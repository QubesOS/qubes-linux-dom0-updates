# Dom0 update packages (obsolete)

This repository is obsolete and is not used by
[qubes-builderv2](https://github.com/QubesOS/qubes-builderv2).

It rebuilt a few packages from a newer Fedora release (Xorg GPU drivers from
Fedora 28) as updates for the older Fedora in dom0, using the legacy
[qubes-builder](https://github.com/QubesOS/qubes-builder).

Backported dom0 packages now each live in their own repository, for example
[qubes-xorg-x11-server](https://github.com/QubesOS/qubes-xorg-x11-server) and
[qubes-xorg-x11-drv-libinput](https://github.com/QubesOS/qubes-xorg-x11-drv-libinput).
